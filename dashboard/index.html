    How the radar works

    Value. Implied value = TVL × category multiple × growth multiplier × maturity multiplier. The category multiple is the median market-cap-to-TVL ratio of the live-token protocols in the same category in this snapshot (at least 3 of them, else the global median, —), clamped to 0.05–1.50. Growth is the 7-day TVL change clamped to −50…+100%, weighted 0.6. Maturity rises with the days a protocol has run with no token recorded, from 0.70 to 1.00 over four years; an unknown listing date scores 0.85.

    Coverage. The board holds all 40 watchlist protocols and every rankable pre-token protocol below the $50M floor — 178 rows in all. Rankable means it records no token, is not a versioned pool, and is not a wrapped, staked, bridged or exchange product. Protocols whose token already trades are set aside in the Live tokens view at their market cap, never mixed into the ranking.

    Farm plans. Each row carries concrete steps with what they cost and how long they take, built from the protocol's own category, chains, TVL and age. A plan is a way to be present before a launch, not a guarantee of one.

    Source: DefiLlama protocol index, fetched 2026-11-14. “Records no token” means the snapshot carries no market cap, CoinGecko id or symbol for the protocol — a protocol on this board may still have a token its record does not carry.
